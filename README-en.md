# Cat and Rabbit Image Dataset

This dataset contains images of cats and rabbits (bunnies) for image classification tasks. It is part of the activities for the bootcamp organized by DIO and BairesDev.

## Dataset Structure

The dataset is organized in two folders:
- `classes/cat/` - Contains 250 images of cats
- `classes/bunny/` - Contains 240 images of rabbits (bunnies)

## Usage

This dataset is designed for machine learning image classification exercises. The images are organized in class folders which makes it easy to use with various machine learning frameworks that support folder-based class organization.

## Activities

This dataset is used for Activity 1 of the DIO and BairesDev bootcamp. It will be used for image classification tasks in subsequent activities.

## Getting Started

To use this dataset:
1. Clone or download this repository
2. Explore the images in the `classes/cat/` and `classes/bunny/` directories
3. Use these images for training image classification models

## Image Sources

The images in this dataset are for educational purposes only. The specific sources of the images are not documented, but they have been collected for use in machine learning training exercises.
