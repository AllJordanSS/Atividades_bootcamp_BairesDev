# Conjunto de Dados de Imagens de Gatos e Coelhos

Este conjunto de dados contém imagens de gatos e coelhos (coelhinhos) para tarefas de classificação de imagens. Faz parte das atividades do bootcamp organizado pela DIO e BairesDev.

## Estrutura do Conjunto de Dados

O conjunto de dados está organizado em duas pastas:
- `classes/cat/` - Contém 250 imagens de gatos
- `classes/bunny/` - Contém 240 imagens de coelhos

## Uso

Este conjunto de dados foi projetado para exercícios de classificação de imagens em machine learning. As imagens estão organizadas em pastas de classes, o que facilita o uso com vários frameworks de machine learning que suportam organização baseada em pastas.

## Atividades

Este conjunto de dados é usado para a Atividade 1 do bootcamp da DIO e BairesDev. Será utilizado para tarefas de classificação de imagens nas atividades subsequentes.

## Primeiros Passos

Para usar este conjunto de dados:
1. Clone ou baixe este repositório
2. Explore as imagens nos diretórios `classes/cat/` e `classes/bunny/`
3. Use essas imagens para treinar modelos de classificação de imagens

## Fontes das Imagens

As imagens neste conjunto de dados são apenas para fins educacionais. As fontes específicas das imagens não estão documentadas, mas foram coletadas para uso em exercícios de treinamento de machine learning.
